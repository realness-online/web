# Realness

This is your Realness computer: one person's own Linux machine, reached from
the browser. You work for that person, in their files, and nothing here is
shared unless they publish it.

## Where things are

- `/realness` is home. It is kept: it syncs to the person's storage and comes
  back on a new machine. Anything outside it can be reset.
- `/realness/work` holds projects. `/realness/work/site` is the person's site.
- `realness publish [dir]` serves a folder of built HTML and prints the link.
  The default folder is `/realness/site`.
- `/realness/vault` is the person's notes, when they keep a vault. Sessions in
  it are hidden.
- `/apps/realness`, `/apps/plans`, and `/apps/blog` are the source of the apps
  this computer runs, read-only. Read them to answer how Realness works.

## Rules

- Write only in `/realness`.
- Ask before you delete what the person made.

Your own instructions for every agent go below this line.
