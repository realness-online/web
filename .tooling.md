# Realness tooling (curated)

Vue/Vite + WASM + Cloudflare workers site (realness.online), Firebase
hosting/storage. Heavy build + deploy + test/risk tooling. Run scripts from
`work/realness`.

## Diagnose / test

- `npm run test:coverage` then `npm run fallow:report` - coverage + refactor-risk health.
- `npm run test:risk` / `test:risk:report` - coverage + fallow + risk report in one.
- `npm run test:risk:report` / `test:coverage:summary` - plaintext risk/summary output.
- `npm run test:fail-fast` - stop at first failure (`--bail=1`).
- `npm run type` - tsc type check. `npm run lint` / `format` (project scripts, not raw npx).
- `npm run test:rules` - Firebase storage rules tests (`firebase emulators:exec`).
- `npm run verify` - verify a deploy (manifest vs site).

## Build / deploy

- `npm run build` - full: icons, wasm, toc, prerender, manifest.
- `npm run deploy` - build + firebase deploy + `verify-deploy`.
- `npm run ship` - deploy + gh release + verify.
- `npm run prerender` parts: `build:prerender`, `build:manifest`, `build:toc`, `build:icons`, `build:wasm`, `build:workers`.

## Dev / serve

- Prefer `https://realness.local` (already running) - do not start another
  `npm run dev` for browser/preview work.
- `npm run dev` - only if nothing is serving; runs `generate-toc.js` first.
  With mkcert certs present, Vite serves HTTPS on `realness.local:443`.
- `npm run serve` - preview build. `serve:https` - serve dist.
- `dev:workers` - watch workers.

## Note

- `npm run check` is docs/vuepress (`vp check`), `docs` is JSDoc.
- `fallow` / `fallow:fix` need a `fallow-report.json`; run `fallow:report` first.
- `og:candidates` / `og:pick` are Open Graph image tooling (rarely needed).
- Deployment uses `verify-deploy.js`; a failed verify means the site drifted from manifest.
