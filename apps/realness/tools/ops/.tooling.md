# Operator tooling

Run from `apps/realness`. No separate ops install.
Functions needs `npm --prefix functions ci` and Node 22.

## Commands

- `npm run traffic -- --help`: options without cloud access.
- `npm run ads -- --help`: options without a key; metrics need `OPENAI_ADS_API_KEY`.
- `npm run repair -- --help`: options without writes.
- `npm run check:functions`: lint; `test:functions`: tests.
- `npm run pre-commit:functions`: lint and tests.
- `npm run serve:functions`: emulator; `logs:functions`: deployed logs.
- `npm run deploy:functions -- --project ID`: deploy only with explicit approval.
- Functions deployment uses `firebase.functions.json`; frontend deployment is separate.
- Functions pins published `@realness.online/thoughts`; update its lockfile after publication.

See [product procedures](../../README.md).
