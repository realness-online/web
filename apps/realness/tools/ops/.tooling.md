# Realness operator tooling

Run commands from `apps/realness`. This folder has no package or install.
Functions keep their own package and Node 22 runtime in `functions/`.

## Operator commands

- `npm run traffic -- --help` lists options without cloud access.
- `npm run ads -- --help` lists options without an API key; metrics require `OPENAI_ADS_API_KEY`.
- `npm run repair -- --help` lists options without making changes.
- `npm run migration:report -- --project ID --bucket NAME` reads an explicit target; `--apply` enables writes.

## Functions checks

- `npm run check:functions` runs lint.
- `npm run test:functions` runs tests; `test:functions:watch` and `test:functions:coverage` retain their modes.
- `npm run pre-commit:functions` runs lint and tests.
- `npm run test:functions:emulators` uses the local demo project.
- `npm run test:functions:gcs` requires cloud credentials and accesses storage.

## Services

- `npm run serve:functions` starts the Functions emulator.
- `npm run logs:functions` reads deployed logs.
- `npm run deploy:functions -- --project ID` deploys only on explicit approval.
- `firebase.functions.json` owns deployment config; `firebase.functions.test.json` owns test emulators.
- Functions pins published `@realness.online/thoughts`. Update the pin only after publication and update its lockfile from `functions/`. Releases use `thoughts-v<version>` tags; no manual npm publish.
