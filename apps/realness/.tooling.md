# Realness tooling

Run from `apps/realness`. One root install; Functions needs `npm --prefix functions ci` (Node 22).

## Checks

- `npm test`: quality, web app, and Functions checks; stops on failure. `npm run spec` runs only the specs.
- Specs mirror source: `specs/<module>` run with `npm run spec:node`, `specs/app` with `npm run test:frontend -- <spec-path>`.
- `npm run check:quality`: backend format/lint, types, dead code, and coverage.
- Live checks sit in `checks/`. `npm run check:halo` needs a running local halo; never use stale `halo-smoke.sh`, it kills the live halo.
- `check:boundary` and `check:pi-exit` need a local halo and spend model tokens; `check:actor-request` also needs admin login.
- Compressed replay tests need the fork reader built: `npm --prefix ../../work/pi/packages/coding-agent run build`.
- Web app: `check:frontend` (format and lint; `:fix` writes), `type`, `test:coverage`, `test:risk`. Run `fallow:report` before `fallow:fix`.
- `npm run test:rules` needs emulator port 9299 free. Use npm scripts rather than `npx vp`.

## Run and deploy

- `npm run reset:local` rebuilds the local stack from scratch: stops the stack,
  deletes the Lima VM (mounts, actors, seed), provisions a fresh VM from
  `server/lima/fc-local.yaml`, rebuilds the actor template, and starts
  `npm run local`. Never touches iCloud data. Ctrl-C stops the stack it starts.

- `npm --prefix ../.. run local -- --dry-run` previews local startup; drop the flag to start it. Reuse running servers.
- Logs: `artifacts/realness/local/`. Proxy key: `artifacts/realness/openrouter-key` (600).
- `npm run icloud:status -- --wait` waits until iCloud reports every container caught up; exit 1 means not ready.
- `npm run realness -- <environment> <command>`: operator commands; environment is required.
- `npm run ship`: next version, tag, deploy every changed target, release, verify. Refuses a dirty worktree; `--dry-run` prints the plan. Halo inputs in `src/settings/layout.js` trigger a halo restart.
- `npm run build` writes `artifacts/realness/frontend/dist/` (`DIST_DIR` overrides); `npm run verify` compares the deployed site with its manifest.
- `npm run realness -- frontend deploy --env development --dry-run` previews; drop `--dry-run` only for an approved deploy.
- `npm version` pushes through `postversion`; never use it as a local-only bump.
- `npm run poster` needs `CHROME_PATH`; `REALNESS_URL` tests local changes. Stop leftover poster browsers by PID.
- `npm run realness -- <env> report [--day=DATE] [--days=N]`: calls, errors, latency, cache, and cost by model, provider, and client. `GET /usage` on the proxy returns the rows.
- The harness watch shows today's calls; `d` opens them. Restart it after code changes.
- Traces: one OTLP `model.call` span per call when `OTEL_EXPORTER_OTLP_ENDPOINT` is set.
- `deploy:proxy` and `deploy:gate` take an explicit environment. `--fresh` wipes actor storage; never use it to diagnose.
- `npm run secret -- NAME [dev|prod]`: store secrets without echoing them.
