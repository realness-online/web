# Realness tooling

Run from `apps/realness`. One root install; Functions needs `npm --prefix functions ci` (Node 22).

## Checks

- `npm test`: quality, frontend, and Functions checks; stops on failure.
- `npm run test:node`: focused Node tests. Frontend: [notes](frontend/.tooling.md).
- `npm run check:quality`: backend format/lint, types, dead code, and coverage.
- Compressed replay tests need the fork reader built first: `npm --prefix ../../work/pi/packages/coding-agent run build`.
- `npm run check:halo`: needs a running local halo. Never use stale `halo-smoke.sh`; it kills the live halo.
- `npm run check:boundary` and `check:pi-exit` need a local halo and spend model tokens.
- `npm run check:actor-request` needs a local halo and admin login; creates and deletes an actor.

## Run and deploy

- `npm --prefix ../.. run local -- --dry-run` previews local startup; drop the flag to start it. Check existing servers first.
- Logs: `artifacts/realness/local/`. Proxy key: `artifacts/realness/openrouter-key` (600).
- `npm run realness -- <environment> <command>`: operator commands; environment is required.
- `npm run ship`: the release. Next version, tag, deploy every changed target, then release and verify its build. Refuses a dirty worktree; `--dry-run` prints the plan. Targets come from the input lists in `src/settings/layout.js`, so expect a halo restart whenever halo inputs move.
- `GET /usage` on the proxy: rows and totals. Operator bearer `OPERATOR_SECRET` (32+ bytes, optional). `?day=YYYY-MM-DD` or `?days=N` up to 31. Rows carry client, provider, latency, cache reads and writes, and cost.
- `npm run realness -- <env> report [--day=DATE] [--days=N]`: calls, errors, p50/p95, cache hit rate, and cost, by model, provider, and client.
- The harness watch shows today's calls and flags errors; `d` opens the calls section. Restart it after code changes.
- The watch traffic tile reads the same archive `npm run traffic` writes. Cache files sit under `artifacts/realness-ops/hosting-traffic/`.
- Traces: one OTLP/HTTP `model.call` span per call when `OTEL_EXPORTER_OTLP_ENDPOINT` is set. No collector ships here. Spans leave out the payer phone.
- `npm run build`: production build.
- `npm run realness -- frontend deploy --env development --dry-run` previews; remove `--dry-run` only for an approved deploy.
- Use the frontend deploy command so hosting config gets the right paths.
- `deploy:proxy` and `deploy:gate` take an explicit environment.
- `--fresh` wipes actor storage. Do not use it to diagnose a running service.
- `npm run secret -- NAME [dev|prod]`: store secrets without echoing them.
