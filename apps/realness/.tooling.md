# Realness tooling

Run from `apps/realness`. One root install; Functions needs `npm --prefix functions ci` (Node 22).

## Checks

- `npm test`: quality, frontend, and Functions checks; stops on failure.
- `npm run test:node`: focused Node tests. Frontend: [notes](frontend/.tooling.md).
- `npm run check:quality`: backend format/lint, types, dead code, and coverage.
- Compressed replay tests need the fork reader built first: `npm --prefix ../../work/pi/packages/coding-agent run build`.
- `npm run check:halo`: needs a running local halo. Never use stale `halo-smoke.sh`; it kills the live halo.
- `npm run check:boundary` and `check:pi-exit` need a local halo and spend model tokens.
- `npm run check:actor-request` needs a local halo and admin login; creates and deletes an actor.

## Run and deploy

- `npm --prefix ../.. run local -- --dry-run` previews local startup; `npm --prefix ../.. run local` starts it. Check existing servers first.
- Local logs: harness `artifacts/realness/local/`. Proxy key: `artifacts/realness/openrouter-key` (mode 600).
- `npm run realness -- <environment> <command>`: operator commands; environment is required.
- `GET /usage` on the proxy: every person's call rows and totals. Operator bearer `OPERATOR_SECRET` (32+ bytes, optional). `?day=YYYY-MM-DD` for one day, `?days=N` up to 31 for a daily series. Rows carry client, provider, latency, cache reads and writes, and cost.
- `npm run build`: production frontend build.
- `npm run realness -- frontend deploy --env development --dry-run`: preview frontend deployment. Remove `--dry-run` only for an approved deploy.
- Use the frontend deploy command so generated hosting config uses the correct output paths.
- `npm run deploy:proxy -- development` and `deploy:gate -- development` require an explicit environment.
- `--fresh` wipes actor storage. Do not use it to diagnose a running service.
- `npm run secret -- NAME [dev|prod]`: store secrets without echoing them.
