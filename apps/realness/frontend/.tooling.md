# Frontend tooling

Package: `apps/realness`.

Run from `apps/realness`, not this directory. Use the root install and npm scripts.

## Checks

- `npm run check:frontend`: format and lint only; `check:frontend:fix` writes changes.
- `npm run type`: frontend type checks.
- `npm run test:frontend -- <test-path>`: focused tests; `test:coverage` adds coverage.
- `npm run test:risk`: coverage, Fallow, and risk report.
- `npm run fallow:report` must precede `fallow:fix`.
- `npm run pre-commit`: format/lint fixes, types, frontend tests, and storage rules tests.
- `npm run test:rules` needs emulator port 9299 free.
- Use npm scripts rather than `npx vp`, which can select a different toolchain.

## Build and serve

- Reuse an existing server; do not start another for preview work.
- `npm run dev:frontend`: start only when no suitable server is running.
- `npm run build`: production build; `serve:frontend`: preview.
- Output normally goes to harness `artifacts/realness/frontend/dist/`; `DIST_DIR` overrides it.
- `npm run verify`: compare the deployed site with the build manifest.
- `npm run ship` is the release: next version, tag, GitHub release, deploy every target whose inputs changed, then verify.
- `npm version` pushes commits and tags through `postversion`; do not use it as a local-only bump.
- `npm run poster` needs `CHROME_PATH`; set `REALNESS_URL` to test local changes. Its default uses the deployed site.
- Stop leftover poster browser processes by PID before rerunning.
